Leonida Ledger — an offline web app that is the best guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with saved progress, filters and a spoiler setting, a roadmap to the platinum, missable trophies flagged, and a guide to each trophy in our own words that cites its sources. Static files that open in a desktop browser and work with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server.
